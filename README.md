# InternNova-Sales-Analysis
Sales Analysis Dashboard — Power BI

1. Project Overview

This project analyzes sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profitability, product categories, regional distribution, and monthly sales trends.

2. Objectives

- Analyze total sales and total profit.
- Calculate profit margin and total orders.
- Compare sales performance across product categories.
- Analyze regional sales distribution.
- Identify monthly sales trends.
- Support business decisions through interactive visualizations.

3. Tools and Technologies

- Microsoft Power BI Desktop — Dashboard creation and visualization.
- Power Query Editor — Data cleaning and preparation.
- DAX (Data Analysis Expressions) — Measures and calculations.

4. Dataset Description

The dataset contains the following fields:

- Order ID
- Order Date
- Ship Mode
- Customer Name
- Segment
- Region
- Category
- Subcategory
- Product Name
- Sales
- Quantity
- Discount
- Profit
- Month

5. Data Preparation

The dataset was imported into Power BI and prepared using Power Query. Data types and text formatting were checked, and duplicate records were reviewed. Separate Products and Customers tables were created for data modeling, with relationships to the Sales table.

6. Dashboard Features

The Sales Analysis Dashboard includes:

- KPI Cards: Total Sales, Total Profit, Total Orders, and Profit Margin.
- Sales by Category: Compares revenue across product categories.
- Sales Distribution by Region: Shows each region's share of sales.
- Monthly Sales Trend: Displays changes in sales across months.
- Detailed Sales Transactions: Provides order- and product-level information.
- Interactive Slicers: Filter by Order Date, Region, Category, and Ship Mode.

7. Key Business Insights

Based on the current dashboard:

- Technology has the highest category sales at approximately $178K.
- Office Supplies has the lowest category sales at approximately $159K.
- The largest regional sales share is approximately 27.61%.
- Monthly sales range from approximately $32.72K to $49.73K.
- The dashboard reports a profit margin of 24.62%.

Note: Verify the Total Sales KPI against the transaction table before final submission, because the displayed totals appear inconsistent.

8. Business Recommendations

- Maintain suitable inventory and targeted marketing for high-performing categories.
- Investigate demand, pricing, and product selection in lower-performing categories.
- Develop targeted strategies for regions with lower sales.
- Use monthly trends to plan inventory and promotional campaigns.
- Monitor discounts and profit margins to support profitable growth.
